# My First Tkinter Game 🎮

My first GUI game made with Python and Tkinter.

A simple number guessing game where you try to guess a randomly generated number.

## 🎯 Features

- Random number generation
- Number guessing system
- Points system
- Tries counter
- Best score
- Input validation
- Simple GUI made with Tkinter

## 🛠️ Built With

- Python
- Tkinter
- Random

## ▶️ How to Play

Enter a number between 0 and 100 and press **Enter**.

The game will tell you if your guess is too high or too low.

Try to guess the number with as few tries as possible!

## 📦 Download

You can download the `.exe` version from this repository and run it without opening the Python source code.
